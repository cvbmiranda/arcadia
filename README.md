# 🎮 Arcadia

**Arcadia** é um projeto desenvolvido para a disciplina de **Orientação a Objetos** da **Universidade de Brasília (UnB)**.

Este sistema reúne alguns jogos simples criados com o objetivo de proporcionar diversão e, ao mesmo tempo, aplicar os conceitos de orientação a objetos em **Python**, utilizando o framework **Flask** para construção da aplicação web.

---

## ⚙️ Requisitos

Antes de iniciar o projeto, certifique-se de ter:

- Python 3 instalado
- Pip (gerenciador de pacotes do Python)

---

## 🚀 Como executar

Siga os passos abaixo para rodar a aplicação localmente:

1. **Clone o repositório** (caso ainda não tenha feito isso):

   ```bash
   git clone https://github.com/seu-usuario/arcadia.git
   cd arcadia
2. Instale as dependências:

   ```bash
   pip install -r requirements.txt

✅ **Atenção:** certifique-se de que o nome do arquivo é exatamente `requirements.txt`.

### 2. Inicie a aplicação:

```bash
python app.py
```

### 3. Acesse no navegador:

[http://localhost:5000](http://localhost:5000)
